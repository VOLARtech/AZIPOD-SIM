Control language · one pattern for every propulsor

Every control shows the same three things: the order (amber handle you move), the actual state (ink needle or bar, which lags the way the real machinery does), and any limit (dashed or hatched: barred speed range, power cap, interlock). Port is red and starboard is green everywhere. Thrusters are cyan in plan views. A trainee who learns one station can read the others.

Engine telegraph

FPP ships. Answer-back arrow lags the handle while the engine slows, stops and restarts.

Shaft rpm

Barred range hatched (passed through quickly). Hatched centre: below minimum running rpm.

Helm · conventional ±35°

Rudder follows at 2.3 °/s (SOLAS: 35° → 30° other side in 28 s).

Helm · Schilling ±70°

High-lift rudders: same widget, scale set by the ship. Flap rudders ±45°.

CPP pitch

Constant shaft rpm, pitch reverses in about 15–20 s. Dashed: PMS power cap.

Azimuth combi-lever

ASD tugs, Z-drives, Azipods. Ring handle = azimuth order, dot = thrust order, arrow = actual.

Voith Schneider pad

Cycloidal propeller: thrust vector set directly in x/y, reaches it in seconds.

Waterjet

Bucket lever (ahead ↔ astern through zero) plus nozzle angle. Bucket down with the nozzle over gives sideways thrust.

Tunnel thruster

Effectiveness shown live: tunnel thrusters lose most of their side force above 3–4 kn.

Tow winch

Tugs. Brake / render / quick-release, with a girting watch on the heel.
